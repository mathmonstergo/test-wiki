# 版本与补丁跟踪机制

在《Apex 英雄》的生命周期中，版本更新日志是最重要、信息密度最高的内容板块。本机制定义 AI Agent 如何处理和沉淀补丁数据。

## 补丁分类标准

1. **赛季大版本 (Major Season Release)**：
   - 伴随新传奇登场、新武器、地图重制及排位赛机制重大革新。
   - 处理方式：由 Agent 创建专属赛季页面（例如 `/apex/seasons/s23.md`），并更新涉及的所有传奇和武器单页。
2. **季中平衡性补丁 (Mid-Season Split / Event Update)**：
   - 集中于武器数值削弱/增强（Nerf / Buff）、传奇技能冷却时间调整、排位赛体验改善。
   - 处理方式：在对应武器/传奇条目下追加“版本变迁”记录，并在补丁索引中归档。
3. **日常热修复 (Hotfix / Bug Fix)**：
   - 修复偶发崩溃、模型穿模或错误判定。
   - 处理方式：汇总进入当季的“已知问题与热修复日志”。

## 结构化数据提取示例

当 Agent 读取到官方补丁公告文本时：

```markdown
> 官方原文摘录：
> 獒犬霰弹枪 (Mastiff Shotgun):
> - 单发每颗弹丸伤害由 11 点提升至 12 点。
> - 弹丸散布范围缩小 8%。
```

Agent 将自动执行：
1. 更新 `docs/apex/weapons/mastiff.md` 中的当前基础属性表。
2. 在该武器页面的“变动历史”表格中追加新赛季改动行。
3. 在补丁日志聚合页生成高亮对比条目：
   - **獒犬霰弹枪**：弹丸单发伤害：`11` ➔ `12`（+9.1%）；散布收紧 `8%`。

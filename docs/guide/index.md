# 项目简介与背景

欢迎查阅 **Apex Legends Wiki** 自动化知识库！

本项目是由 **DeepSeek 最新推出的 Super Agent (DeepSeek Harness)** 框架驱动、AI 自主维护的《Apex 英雄》(Apex Legends) 知识库系统。

## 项目起源与探索初衷

在游戏领域，特别是像《Apex 英雄》这样的快节奏多人竞技射击游戏中，游戏内容高频迭代：每个赛季都有新传奇、新武器、地图轮换、武器数值平衡调整以及系统级机制改动。传统的游戏 Wiki 往往依赖大量核心玩家和社区志愿者的手工编辑，容易出现信息滞后、格式不一、细节遗漏等问题。

与此同时，DeepSeek 推出了新一代 **Super Agent 框架**。该框架具备强大的通用任务推理、工具编排与多步骤自主执行能力：

- **通用性与广泛流程**：Super Agent 原生设计是通用型的自主智能体系统，其整体逻辑流程具备广泛的适应性（支持环境交互、多工具调用、自检反思与自动化交付），而非专为搭建 Wiki 设计。
- **特定场景实践（练手试点）**：正因其通用性，我们选择以《Apex 英雄》Wiki 为练手项目，探索如何对 Super Agent 的底层逻辑流程进行定制和源码级适配，将其能力具象化落地为一套**可自主运行、持续从官方消息源拉取并更新内容的游戏 Wiki**。

## 核心目标

1. **官方消息源实时监控**：
   对接 EA/Respawn 官方网站、Steam 更新日志、Apex 官方博客及社交媒体等权威渠道。
2. **AI 自主内容结构化**：
   借助大语言模型的情报提炼能力，自动解析非结构化的官方公告，提炼英雄技能数值变动、武器 TTK 差异、赛季通行证机制等关键要素。
3. **工程化持续集成与发布**：
   通过 Git 自动化提交流程与 GitHub Actions，构建自动发 PR、自动检查、自动部署至 GitHub Pages 的完整 DevOps 链路。
4. **验证通用 Agent 的垂直落地形态**：
   为后续基于 DeepSeek Super Agent 拓展更多领域（技术文档、产品手册、开源社区知识库等）沉淀通用模板与改造成果。

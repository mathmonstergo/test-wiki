# 参考资料索引

本页面汇总项目调研与开发过程中积累的重要官方文档、开源规范及深度技术参考资料。

## 官方技术文档

- **VitePress 官方文档**：[https://vitepress.dev/](https://vitepress.dev/)
  - 了解 VitePress 的 Markdown 扩展语法、Frontmatter 配置与自定义主题机制。
- **TypeScript 官方手册**：[https://www.typescriptlang.org/docs/](https://www.typescriptlang.org/docs/)
  - 类型体操、模块解析与最佳实践参考。
- **Node.js 官方文档**：[https://nodejs.org/docs/](https://nodejs.org/docs/)
  - LTS 版本 API 参考与标准库文档。

## 架构与工程规范

- **Conventional Commits 规范**：[https://www.conventionalcommits.org/](https://www.conventionalcommits.org/)
  - 结构化提交规范，便于自动生成 Changelog 与版本标记。
- **Semantic Versioning 语义化版本**：[https://semver.org/lang/zh-CN/](https://semver.org/lang/zh-CN/)
  - `MAJOR.MINOR.PATCH` 版本递增规则。
- **12-Factor App 现代应用构建准则**：[https://12factor.net/zh_cn/](https://12factor.net/zh_cn/)
  - 云原生应用配置、无状态、日志流与环境隔离指导思想。

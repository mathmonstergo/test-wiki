# Super Agent 自动维护全景架构

本项目将 GitHub 仓库本身作为 Wiki 的唯一真实载体，并以 GitHub 原生工具链作为整个知识库的管理中枢，结合 DeepSeek Super Agent 实现闭环的自治运维。

---

## 架构核心三要素

```text
┌──────────────────────────────────────────────────────────────┐
│                    1. 官方消息感知层                          │
│   EA News RSS / Steam Web API / Trello Board / Twitter API   │
└──────────────────────────────┬───────────────────────────────┘
                               │ 发现变动 / 触发事件
┌──────────────────────────────▼───────────────────────────────┐
│               2. GitHub 协同管理中枢 (Management Hub)         │
│   ┌────────────────────┐            ┌────────────────────┐   │
│   │   GitHub Issues    │            │   Pull Requests    │   │
│   │ (变动工单/情报登记) │            │ (变更提审/Diff验证) │   │
│   └────────────────────┘            └────────────────────┘   │
│   ┌────────────────────┐            ┌────────────────────┐   │
│   │   GitHub Actions   │            │  Git History/Wiki  │   │
│   │ (CI校验/自动化调度) │            │ (Markdown 单一信源)│   │
│   └────────────────────┘            └────────────────────┘   │
└──────────────────────────────┬───────────────────────────────┘
                               │ 调度 / 执行
┌──────────────────────────────▼───────────────────────────────┐
│             3. DeepSeek Super Agent 核心驱动引擎             │
│   - 长文本解析与游戏专业名词对齐                             │
│   - 结构化 Diff 计算 (平衡性数值变动提取)                    │
│   - 自动化工作区多文件编辑、格式校验与分支管理               │
└──────────────────────────────────────────────────────────────┘
```

---

## 各组件协同关系

1. **GitHub Issues 作为事件总线**：
   无论是外部官方监测系统发现新公告，还是社区玩家提交勘误，均汇总为标准化的 GitHub Issue，提供清晰的工单上下文与追踪链。
2. **DeepSeek Super Agent 作为自主执行者**：
   读取 Issue，使用工具获取官方完整公告，调用推理能力分析变动，在本地工作区内对 `wiki/` 目录中的多个 Markdown 文档进行增量更新。
3. **GitHub Pull Requests 作为安全围栏**：
   Agent 不直接向生产主分支 `main` 推送未审查内容，而是发起具备完整变更说明与官方对比凭据的 PR，交由 CI 检查与团队 Review。

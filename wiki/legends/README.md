# 传奇档案体系总览

《Apex 英雄》中的传奇分为五大职阶，各职阶具备独特的职阶特长（Class Perks），影响全队的战术策略。

---

## 职阶特长体系

| 职阶类别 | 核心定位 | 专属职阶特长 (Class Perks) |
| :--- | :--- | :--- |
| **突击 (Assault)** | 火力压制与突破 | 可开启红色武器补给箱暗格；轻型/重型/能量弹药背包每格堆叠量 +20 |
| **散兵 (Skirmisher)** | 机动拉扯与转点 | 远距离勘测并标记照护舱（空投）中的最高价值物品；高机动转移技能 |
| **侦察 (Recon)** | 战场情报与索敌 | 可使用勘测信标扫描全地图敌人当前位置（持续一段时间）；缩圈雷达强化 |
| **控制 (Controller)** | 阵地封锁与防守 | 可使用环圈控制台提前获取下一圈位置；强化防守掩体与陷阱布设 |
| **支援 (Support)** | 团队续航与救援 | 可在复制器合成队友旗帜卡；可开启蓝色补给箱暗格；更快拉起队友并提供生命恢复 |

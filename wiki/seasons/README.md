# 赛季与版本变迁总览

《Apex 英雄》以约三个月为一个赛季周期，每个赛季带来系统级大更新，赛季中穿插分段更新与重大平衡性热修。

---

## 赛季版本归档模型

在 GitHub 仓库中，每个重大版本在 `wiki/seasons/` 下拥有独立的归档文档与 Git 历史版本记录：

```text
wiki/seasons/
├── README.md               # 赛季归档总览索引（本页）
├── current-season.md       # 当前最新活跃赛季与核心变迁
├── patch-tracking.md       # 官方消息源捕获与补丁跟踪机制
└── archives/               # 往期赛季历史归档
```

---

## 核心机制演进简史

1. **护甲系统升级**：由最初的“纯拾取护甲”演变为“全员 EVO 升级护甲机制”，再演变为通过队伍升级核心 (Legend Upgrades) 获得护甲与被动天赋选择。
2. **传奇职阶重塑**：重构为突击、散兵、侦察、控制、支援五大职阶并配备独特的团队被动特长。
3. **武器双持与配件革新**：引入轻型/重型自适应枪械、双持莫桑比克与 P2020 等革命性玩法。

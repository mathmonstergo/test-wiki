# 武器军械库体系总览

《Apex 英雄》的枪械系统涵盖多种弹药类别与武器类别，各武器在射程、射速、弹道速度、弹夹容量与配件扩展性上各具特色。

---

## 弹药分类

| 弹药类型 | 特点 | 代表武器 |
| :--- | :--- | :--- |
| **轻型弹药 (Light)** | 射速极快、衰减相对平缓、近战爆发力强 | R-99, R-301, P2020, RE-45 |
| **重型弹药 (Heavy)** | 单发破坏力大、压制力强、中距离弹道扎实 | 平行步枪 (VK-47 Flatline), 赫姆洛克, CAR |
| **能量弹药 (Energy)** | 弹道速度极快、下坠小、多具备蓄力或特殊机制 | 哈沃克 (HAVOC), 电能冲锋枪 (Volt), 复仇女神 (Nemesis) |
| **霰弹弹药 (Shotgun)** | 近距离多弹丸散布、高爆发致命打击 | 和平捍卫者 (Peacekeeper), 獒犬 (Mastiff), 莫桑比克, EVA-8 |
| **狙击弹药 (Sniper)** | 超远射程、高单发伤害、弹道下坠计算 | 哨兵 (Sentinel), 长弓 (Longbow), 充能步枪 (Charge Rifle) |
| **特殊空投弹药 (Mythic/Care Package)** | 仅限空投神话武器，弹药有限不可补充 | 克雷贝尔 (Kraber .50-Cal) 等 |
